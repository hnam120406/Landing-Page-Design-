# Flash Honner Media Asset Brief

## Purpose

This document defines the production handoff for the missing Flash Honner
media assets. It does not represent existing files. The project is a software
development service, so every visual must communicate software product design
and cross-platform delivery rather than physical hardware manufacturing.

## Brand Direction

- Brand: Flash Honner
- Service: Product Design and Development
- Vietnamese positioning: Thiết kế & Phát triển Sản phẩm số
- Business focus: Thiết kế và phát triển các giải pháp phần mềm Web, Mobile và
  Desktop theo nhu cầu thực tế của từng dự án.
- Visual style: clean premium technology, modern, professional, trustworthy,
  lightweight
- Canvas: white or soft-neutral background
- Primary accent: `#F97316`
- Soft accent: `#FFF7ED`
- Main text: `#0F172A`
- Secondary text: `#334155`
- Border: `#E2E8F0`
- Typography direction: Be Vietnam Pro or a visually compatible Vietnamese font
- Shadows: restrained and soft

Avoid marketplace styling, blue-heavy identity, cyberpunk, gaming aesthetics,
and exaggerated technology effects.

## Media Rules

- Show concept UI only; do not imply a real client deployment.
- Label future visual work as Flash Honner concept UI or Flash Honner
  product-development mockup where context requires it.
- Do not show fake customer logos, company names, testimonials, revenue,
  user counts, transactions, personal data, or customer screenshots.
- Use neutral illustrative values, abstract bars, or shapes instead of business
  claims and realistic production data.
- Do not create hardware renders that imply Flash Honner manufactures devices.
- Do not create or download assets as part of this brief.

### Visual Brief

Create a premium multi-device software-product composition representing a
connected Web Admin, Mobile App, and optional Desktop experience. The main Web
